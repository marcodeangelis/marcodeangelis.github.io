# Marco de Angelis

Researcher in Engineering, University of Strathclyde · https://marcodeangelis.github.io

I work on computing with imprecision and formal verification with computer arithmetic:
propagating uncertainty through models so we can draw rigorous inferences from scarce data,
and build trust in cyber-physical systems.

Centre for Intelligent Infrastructure, Glasgow.
